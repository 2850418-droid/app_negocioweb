¿Cómo se guardan mis datos?

Este proyecto educativo utiliza localStorage. No hay servidor ni base de datos real.

¿Cómo funciona el pago?

El checkout registra el método elegido como una demostración; no procesa cobros reales.

¿Cómo solicito una devolución?

Desde tu perfil, abre un pedido y registra una justificación.

¿Cómo genero una factura?

Después de una compra puedes abrir la factura y usar la opción de impresión del navegador para guardarla como PDF.
